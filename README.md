# 💪 AI Fitness Guidance Chatbot

An AI-powered fitness guidance application that provides personalized workout, BMI, calorie, nutrition, and hydration guidance based on the user's fitness level.

The application uses **LangChain and Groq LLM** for AI-generated guidance, **Pydantic** for structured JSON responses, **Langfuse** for prompt management and tracing, and **Streamlit** for the interactive dashboard.

---

## 🚀 Features

- 💬 Personalized AI Fitness Guidance
- 🏋️ Beginner, Intermediate, and Advanced fitness levels
- ⚖️ BMI Calculation and AI Guidance
- 🔥 BMR and Calorie Guidance
- 🥗 Nutrition and Hydration Suggestions
- 📦 Structured JSON Output
- 🕘 Recent Question History
- 🧹 Clear Chat History
- 📊 Langfuse Prompt Management and Tracing
- ☁️ AWS EC2 Deployment
- 🖥️ Interactive Streamlit Dashboard

### Main Files

**app.py**
- Creates the Streamlit dashboard.
- Handles Fitness, BMI, and Calorie Guidance interfaces.
- Displays AI-generated structured output.

**main.py**
- Controls the main AI workflow.
- Connects the prompt, LLM, and output parser.

**utils/model.py**
- Configures the AI model used by the application.

**utils/prompt.py**
- Handles fitness prompts and Langfuse prompt management.

**utils/parser.py**
- Defines the Pydantic response schema and structured output format.

**utils/validations.py**
- Validates user input before sending it to the AI pipeline.

## 📦 Structured JSON Output

The chatbot generates responses in a structured format:

```json
{
    "title": "Beginner Workout Plan",
    "category": "Fitness and Exercise",
    "fitness_level": "Beginner",
    "response": "Personalized fitness guidance generated by the AI model."
}
```

The structured response makes the output predictable, readable, and easier to use in other applications or APIs.

## 💬 Fitness Chatbot

Users can ask questions such as:

- How to lose weight safely

- Best hydration tips

---

## ⚖️ AI BMI Guidance

The BMI module accepts:

- Weight in kilograms
- Height in meters
- Fitness level

BMI is calculated using:

```text
BMI = Weight (kg) / Height² (m²)
```

The dashboard displays the calculated BMI and category before generating AI-based fitness and nutrition guidance.

---

## 🔥 AI Calorie Guidance

The calorie module uses:

- Age
- Gender
- Weight
- Height
- Fitness goal
- Fitness level

The application estimates the user's BMR and sends the information to the AI workflow to generate calorie, nutrition, and fitness guidance.

Supported goals include:

- Weight Loss
- Maintain Weight
- Muscle Gain

## ☁️ AWS EC2 Deployment

The application can be deployed on an AWS EC2 instance using Streamlit.

Example:

```bash
streamlit run app.py --server.port 8501 --server.address 0.0.0.0
```

For background execution:

```bash
nohup streamlit run app.py --server.port 8501 --server.address 0.0.0.0 > streamlit.log 2>&1 &
```

## 💻 Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/shanigalanikitha/AI_FITNESS_GUIDANCE_CHATBOT.git
```

### 2. Open the project directory

```bash
cd AI_FITNESS_GUIDANCE_CHATBOT
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure environment variables

Create a `.env` file and configure the required API credentials.

**Do not upload the `.env` file or API keys to GitHub.**

### 7. Run the application

```bash
streamlit run app.py
```

## 🔐 Environment Variables

The project requires API credentials for services such as Groq and Langfuse.

Store credentials securely in `.env`.

Example variable names:

```text
GROQ_API_KEY
LANGFUSE_PUBLIC_KEY
LANGFUSE_SECRET_KEY
LANGFUSE_HOST
```

Make sure `.env` is included in `.gitignore`.
